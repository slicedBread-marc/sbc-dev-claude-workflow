# Project Purpose

This project is a development workflow library. All `wf-*` skills (wf-init, wf-status, wf-spec, wf-implement, wf-test, wf-review, wf-release, etc.) are designed to be deployed to other projects — they form a reusable workflow harness that can be dropped into any codebase to provide a structured development pipeline.

Work in this repo is about building, improving, and maintaining that library, not about implementing features for this repo itself.
